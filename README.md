SISTEMA DE GESTÃO DE OBJETOS ACHADOS E PERDIDOS
(INSTITUTO SUPERIOR POLITECNICO DE TETE)


Uma plataforma web moderna e intuitiva desenvolvida para centralizar, otimizar e digitalizar a gestão de itens perdidos e encontrados no âmbito académico do Instituto Superior Politécnico de Tete. 
O sistema visa substituir processos manuais, reduzir o tempo de espera e aumentar significativamente a taxa de recuperação de pertences através de um ecossistema centralizado e de fácil utilização para toda a comunidade estudantil e administrativa.


Funcionalidades
I.	Registo de Objetos: Cadastro detalhado de itens encontrados, permitindo incluir categorias, descrições precisas e o local/bloco onde foram vistos.
II.	Consulta Inteligente: Sistema de busca e filtragem rápida para que alunos e funcionários possam localizar pertences perdidos com facilidade.
III.	Fluxo de Reivindicação: Processo digital que permite ao utilizador solicitar a posse de um objeto encontrado, iniciando uma validação de propriedade.
IV.	Gestão Administrativa:Painel robusto para moderadores e administradores controlarem utilizadores (alunos, funcionários), gerirem permissões e atualizarem o estado dos objetos.
V.	Notificações e Estados:Controlo em tempo real do ciclo de vida do objeto (Pendente, Reivindicado, Entregue), mantendo as partes informadas sobre o estado dos pedidos.



Tecnologias Utilizadas
O sistema foi desenvolvido seguindo o modelo de arquitetura desacoplada (Client-Server), garantindo modularidade e facilidade de manutenção.

Frontend: Responsável por entregar uma interface web fluida, responsiva e de alto desempenho para o utilizador.
I.	React
II.	Vite
III.	React Router Dom
IV.	Axios
V.	JavaScript

Backend:Responsável por gerir as regras de negócio, autenticação, segurança e comunicação com os dados.
I.	Node.js
II.	Express
III.	Cors
IV.	Dotenv

Base de Dados
I.	Supabase (PostgreSQL)

Infraestrutura e Deploy
Vercel: Hospedagem da camada frontend
Render: Hospedagem do servidor backend
